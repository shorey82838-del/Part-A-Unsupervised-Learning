# Part-A-Unsupervised-Learning
Practical implementation of Unsupervised and Reinforcement Learning using Python. Covers customer segmentation with K-Means Clustering, cluster visualization, business interpretation, and basic Reinforcement Learning concepts including agents, actions, rewards, exploration, and exploitation.
Unsupervised & Reinforcement Learning Practical
This repository contains a practical introduction to Unsupervised Learning and Reinforcement Learning using Python and business-oriented examples.

The practical is designed to focus not only on Python implementation but also on understanding how machine learning outputs can support business decision-making.

📌 Topics Covered
1. Customer Segmentation using K-Means
The first part demonstrates how K-Means Clustering can be used to divide customers into groups based on:

Monthly Spending
App Visits
The notebook uses 3 clusters to identify natural customer groups.

The clustering process includes:

Creating a customer dataset
Selecting relevant features
Applying K-Means
Visualizing customer clusters
Viewing customers cluster by cluster
Interpreting clusters from a business perspective
Possible business applications include:

Premium customer identification
Customer engagement analysis
Personalized recommendations
Loyalty programs
Customer re-engagement campaigns
2. Introduction to Reinforcement Learning
The second part introduces the basic concept of Reinforcement Learning using a delivery-route example.

A delivery company has two possible routes:

Route A
Route B
The system receives a reward based on delivery performance and can learn which route tends to perform better.

The practical explains the core Reinforcement Learning components:

Component	Example
Agent	Delivery decision system
Environment	Roads and traffic
Action	Choose Route A or Route B
Reward	Delivery performance feedback
3. Exploration vs Exploitation
The notebook also demonstrates the difference between:

Exploration Trying a new or less-used option to gather more information.

Exploitation Choosing the option that is already known to provide better results.

The practical demonstrates both concepts using the delivery-route example.

📊 Customer Segmentation
The dataset contains eight example customers with their monthly spending and number of app visits.

K-Means is configured with:

KMeans(n_clusters=3, random_state=42, n_init=10)
The resulting cluster numbers are simply group identifiers. They do not automatically represent good, average, or bad customers.
